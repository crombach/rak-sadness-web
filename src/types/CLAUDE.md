# src/types

ESPN scoreboard shapes (EspnEvent, EspnCompetitor, GameStatus); League/SeasonType/WeekInfo/LeagueInfo; LeagueResult/GameSide/Possession, a game with its event id, each side's record, logo, name in halves and quarter scores, its venue, and the link to ESPN's own tracker; WeekGame/GameSpread, one picks column, the game it was picked against, and the pool's line on it from the favored side; GameScore pick-scoring result; RakMadnessScores/PlayerScore/PickResult/Status; PlayerAnalysis, a union over knockedOut, clinched, headline, and paths, so a summary cannot render a field that was never worked out.
